# বদরকণ্ঠ তারুণ্য মঞ্চ — রক্তদাতা তালিকা

বাংলা, রেসপন্সিভ, ডার্ক/লাইট মোডসহ রক্তদাতা তালিকার ওয়েবসাইট। অ্যাপের মতো ইনস্টল করা যায় (PWA)। পুরোপুরি ফ্রি সেবায় চলে (GitHub Pages + Supabase)।

## ফোল্ডারে কী আছে
- `index.html`, `css/style.css`, `js/app.js` — পুরো সাইট
- `js/config.js` — **এখানে Supabase-এর দুটি তথ্য বসাতে হবে**
- `supabase/schema.sql` — ডাটাবেস সেটআপ (একবার চালাতে হবে)
- `manifest.webmanifest`, `sw.js`, `assets/` — অ্যাপ ইনস্টল ও আইকন

## ধাপ ১: Supabase সেটআপ (ফ্রি)
1. https://supabase.com এ অ্যাকাউন্ট খুলে **New project** বানান (পাসওয়ার্ড লিখে রাখুন)।
2. বাঁ মেনুর **SQL Editor → New query** খুলুন। `supabase/schema.sql` ফাইলের পুরো লেখা কপি-পেস্ট করে **Run** চাপুন।
3. **Project Settings → API** থেকে `Project URL` আর `anon public` key কপি করুন।
4. `js/config.js` ফাইলে `YOUR_SUPABASE_URL` ও `YOUR_SUPABASE_ANON_KEY` জায়গায় সেগুলো বসান।
   (শুধু `anon` key বসাবেন, `service_role` key কখনোই নয়।)
5. **Authentication → Providers → Email**: শুরুতে পরীক্ষার জন্য চাইলে "Confirm email" বন্ধ রাখতে পারেন। চালু রাখলে নতুন ব্যবহারকারীকে ইমেইল যাচাই করতে হবে।

## ধাপ ২: GitHub-এ প্রকাশ
1. GitHub-এ নতুন repository খুলুন (Public), যেমন `blood-donors`।
2. VS Code-এ এই ফোল্ডার খুলে GitHub-এ push করুন (বা GitHub ওয়েবসাইটে **Add file → Upload files** দিয়ে সব ফাইল তুলুন; `.nojekyll` ফাইলটিও)।
3. Repository → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save।
4. কিছুক্ষণ পর সাইট পাবেন: `https://আপনার-ইউজারনেম.github.io/blood-donors/`
5. Supabase → **Authentication → URL Configuration → Site URL**-এ এই ঠিকানা বসান (ইমেইল লিংক ঠিকমতো কাজ করার জন্য)।

## ধাপ ৩: নিজেকে ডেভেলপার বানান
1. সাইটে গিয়ে **লগইন → নতুন অ্যাকাউন্ট** থেকে নিজের ইমেইলে অ্যাকাউন্ট খুলুন।
2. Supabase **SQL Editor**-এ এটি চালান (ইমেইল বদলে নিন):
   ```sql
   update public.profiles set role = 'developer' where email = 'আপনার@ইমেইল.com';
   ```
3. সাইটে লগআউট করে আবার লগইন করুন। মেনুতে **ডেভেলপার প্যানেল** দেখা যাবে।

## ডেভেলপার প্যানেলে যা করা যায়
- **রক্তদাতা তালিকা**: অনুমোদন/বাতিল, নতুন যোগ, সম্পাদনা, মোছা
- **ব্যবহারকারী**: যে কাউকে মডারেটর বানানো বা সাধারণ ভূমিকায় ফেরানো
- **সেটিংস**: সংগঠনের নাম, পরিচিতি, যোগাযোগ, ডেভেলপার পরিচিতি, বিকাশ/নগদ/রকেট নম্বর, এবং "অনুমোদন ছাড়াই তালিকায় আসবে কিনা"

মডারেটর শুধু রক্তদাতা তালিকা সামলাতে পারে; সেটিংস, ডোনেশন নম্বর বা অন্যের ভূমিকা বদলাতে পারে না। এই নিয়ম ডাটাবেস স্তরেই কড়াভাবে আটকানো।

## গোপনীয়তা ও নিরাপত্তা নোট
- ফোন নম্বর সবার জন্য খোলা (আপনার সিদ্ধান্ত অনুযায়ী)। তাই রেজিস্ট্রেশনে সম্মতির টিক বাধ্যতামূলক এবং ডোনার নিজে নাম সরাতে পারেন।
- নতুন নিবন্ধন ডিফল্টে মডারেটরের অনুমোদন লাগে, এতে ভুয়া তথ্য কমে।
- অপ্রাপ্তবয়স্ক বা অসুস্থ কেউ যেন তালিকায় না আসেন, সেটি মডারেটররা দেখবেন।

## ডেমো মোড
`js/config.js` না বদলালে সাইট নমুনা তথ্য দিয়ে চলে (শুধু দেখার জন্য)। ফাইল `index.html` সরাসরি না খুলে স্থানীয়ভাবে দেখতে চাইলে ফোল্ডারে `python3 -m http.server 8000` চালিয়ে http://localhost:8000 খুলুন।

## অ্যাপ হিসেবে ইনস্টল
ফোনের Chrome-এ সাইট খুলে **"অ্যাপ হিসেবে ইনস্টল করুন"** বাটনে চাপুন (আইফোনে Safari → Share → Add to Home Screen)।

## আপডেট দিলে
`sw.js`-এর `VERSION` সংখ্যা বাড়িয়ে দিন (`v1` → `v2`), তাহলে পুরোনো ক্যাশ বদলে যাবে।
